# Contributing

Dzieki za chec pomocy!

## Srodowisko

```
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

## Testy

```
pytest
```

## Lint/format (opcjonalnie)

```
ruff .
black .
```

## Zasady

- Tworz osobne branche na zmiany.
- Dodawaj lub aktualizuj testy, jesli to ma sens.
- Dbaj o czytelnosc i spojnosc stylu.
